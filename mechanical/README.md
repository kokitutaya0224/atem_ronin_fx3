# RSAポート接続コネクタ — 設計メモ

## 重要な発見（2026-09-01）

DJI R SDK文書 v2.5 Figure 39（p.19）のRSA/NATOポート図と、ユーザーが撮影した
RS4 Pro実機の写真を突き合わせたところ、**形状が一致しないことが判明した**。

- **文書の図（RS2世代）**: 突起した接点ピンが並ぶ「差し込み型」コネクタ
- **RS4 Pro実機（写真）**: 平面の金メッキパッドが**2×3グリッド（6接点）**で
  並び、上下にM4ボルト穴があってアクセサリをボルト留めしポゴピンを
  押し付ける方式。突起ピンは一切ない

これまで前提にしていたSTL（`3d-print-ronin-can-connector.stl`、先行プロジェクト
[rileycoyote87/DJI-Ronin-RS2-Log-and-Replay](https://github.com/rileycoyote87/DJI-Ronin-RS2-Log-and-Replay)
由来）は**RS2の8コンタクト差し込み型**を想定した設計であり、RS4 Proの
6パッド・ボルト留め構造にはそのまま合わない可能性が高い。これがRSAポート
不通が長引いている根本原因とみられる。

信号の意味（Pin1=VCC, 2=CANL, 3=SBUS_RX, 4=CANH, 5=AD_COM, 6=GND）自体は
公式文書ベースで確度が高いが、**実物での物理配置（どのパッドがどのピン
番号か）は左右ポート回転対称の注記もあり未確定**。ボルト穴側から見た配置は
テスター導通確認で決めるしかない。

## このディレクトリの中身

- `rsa_pogo_housing.scad` — パラメトリックなポゴピン変換ハウジング設計
  （[OpenSCAD](https://openscad.org/)、無料）。実測値を上部の
  PARAMETERSセクションに埋めるだけで、RS4 Pro実物に合わせたモデルを
  生成できる

## 進め方（低コストで前に進める手順）

### ステップ1: 採寸（ノギス必須）

実機のRSAポートで以下6項目を測ってSCADファイルの★印パラメータへ入力する:

| 項目 | SCAD変数 | 測り方 |
|---|---|---|
| パッド横方向ピッチ | `pad_pitch_col` | 同じ行の隣接パッド中心間 |
| パッド縦方向ピッチ | `pad_pitch_row` | 同じ列の隣接パッド中心間（2行しかないので1回でOK） |
| パッド直径 | `pad_diameter` | パッド1個の接触面の直径 |
| M4穴の中心間距離 | `mount_hole_spacing` | 上のボルト穴〜下のボルト穴 |
| パッドグリッド中心からのM4穴オフセット | `mount_hole_offset_x` | 穴がグリッド中心の真上下でなければ測る（真上下ならゼロでよい） |
| パッド面の窪み深さ | `pad_recess_depth` | 取り付け面（ボルト座面）からパッド面までの深さ |

スマホのマクロ撮影＋ノギスを並べて写真を撮っておくと後で見返せて確実。

### ステップ2: 位置確認プレートだけ印刷

`TEST_MODE = true` のまま（デフォルト）で `openscad -o test.stl rsa_pogo_housing.scad`
（またはOpenSCAD GUIでF6→STL export）し、**穴が開いただけの薄い板**を印刷する。
実機にボルト仮止めして6つの穴がすべてパッドに正しく重なるか確認する。
ズレていたらパラメータを微調整して再印刷（薄板なので印刷は数分で終わる）。

### ステップ3: フルモデルへ

穴位置が合ったら `TEST_MODE = false` にして再生成。ポゴピン圧入・配線室・
AD_COMプルダウン抵抗ポケットを含むフルモデルが出力される。ポゴピンは
Preci-Dip 811-S1系を想定しているが、**発注前に必ずデータシートで
バレル外径を確認し `pogo_bore_dia` を合わせること**（圧入がゆるいと
接触不良の再発になる）。

### ポゴピンの固定（接着）方法

旧STLは前面から配線室まで同じ太さの穴が1本貫通しているだけで、
①ピンの保持が摩擦（圧入）任せ ②接着剤を入れる場所がない、という
構造だった。これが実機で試した際の「スコスコ（緩い）」の直接原因と
みられる。新設計は**二段ボア**にしてこれを解消している。

- **前面ランド**（`pogo_bore_dia` × `pogo_land_len`）: パッド面直下、
  ピン外径にきっちり合わせた圧入代。ここが直進性（パッドに垂直に立つ）
  を出す部分で、かつ長さがあることで接着剤が毛細管現象で接点面まで
  染み出るのを防ぐ壁にもなる
- **後方ポケット**（`pogo_glue_pocket_dia`）: 配線室側に大きく開いた
  空間。配線室自体が外に開放されているので、ここへエポキシ/UV硬化樹脂を
  流し込んでピンを恒久固定できる。接点面には接着剤が一切回らない

組み立て手順:
1. ピンを後ろ（配線室側）からランドへ通し、先端がパッド接触に必要な
   突き出し量になるまで押し込む。ハウジング前面を平らな治具やガラス板に
   当てて全ピンを同時に押すと6本の高さが揃う
2. マスキングテープ等で仮固定し、後方ポケットにエポキシを注入
3. 硬化を待ってから配線（ハンダ）

Preci-Dip 811-S1系にツバ（フランジ）があれば、`pogo_land_len` を
そのフランジ位置に合わせるとポケットの段差がハードストップになり、
さらに高さ精度が上がる（データシート確認のうえ調整）。

### 設計上の工夫: AD_COMプルダウン抵抗をコネクタに内蔵

RSAポートはPin5(AD_COM)を10〜100kΩでGNDへプルダウンしないとVCCを
出力しない仕様（Figure 39）。これをESP32/ブリッジ基板側の配線に頼ると
「繋ぎ忘れ」が起きうる（2026-08-31のブリングアップで実際に疑われた）ため、
このハウジング自体に抵抗を内蔵するポケットを設けた。コネクタさえ挿せば
毎回自動的に条件を満たす設計にしている。

## 並行して検討すべきバイパス案

3Dプリント治具の完成を待たずにRonin側の通信を先に確認したい場合、
**DJI R Focus Wheel純正品を1台購入してケーブルだけ流用する**案が
既に候補に上がっている（本体README参照）。純正品はRSAポートに
確実に嵌合するため、パッド位置の測定・治具設計・印刷の試行錯誤を
まるごとスキップできる。値段と入手性次第だが、通信確認だけを急ぐなら
こちらの方が早い可能性が高い。
